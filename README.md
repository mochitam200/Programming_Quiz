# C++基礎クイズアプリ (C++ Programming Quiz)

C++初心者がプログラミングの基礎知識を楽しく学べる、コンソール形式のクイズアプリケーションです。

---

## 📌 プロジェクト概要

本プロジェクトは、C++の基礎文法や概念（変数、型、制御構文、配列、クラス、STLなど）をクイズ形式で学べるC++学習用アプリケーションです。
CSVファイルからクイズデータを動的に読み込み、ランダムに問題を出題します。各問題には丁寧な解説が付いており、復習しながら理解を深めることができます。

### 作成目的
* C++の基礎知識をアウトプットしながら楽しく定着させること
* C++を用いたコンソールアプリケーション開発、ファイルI/O（CSVパース）、STL（`std::vector`や`std::mt19937`等）、クラス設計の実践

---

## ✨ 主な機能（Features）

- 🎲 **ランダム問題出題**: メルセンヌ・ツイスター（`std::mt19937`）を用いて出題順を毎回ランダムにシャッフル
- 📂 **CSVデータ動的読み込み**: クイズ問題を外部CSVファイル（`quiz_list.csv`）から自動読み込み
- 🛡️ **堅牢なパース機能**: カンマを含む問題文や改行コード `\n`、ダブルクォートエスケープに対応
- 💡 **解説付き正誤判定**: 選択肢（A/B/C/D）入力時に正誤を即座に判定し、詳細な解説を表示
- 📊 **成績・評価計算**: 全問解答後に正答率（%）とスコアに応じた評価メッセージを表示
- ⚠️ **入力バリデーション**: 無効なキー入力やデータの不整合に対するエラーハンドリングを完備

## 🚀 セットアップ／インストール手順（Installation）

### 実行ファイルから動かす場合（配布版）

1. リポジトリまたは配布用のアーカイブから `Programming_Quiz_App` フォルダをダウンロード・解凍します。
2. `Programming_Quiz_App` フォルダ内に `data/quiz_list.csv` が正しく配置されていることを確認します。

### ソースコードからビルドする場合

1. このリポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/mochitam200/Programming_Quiz.git
   ```
2. Visual Studio 2022 で `Programming_Quiz.slnx` または `Programming_Quiz.vcxproj` を開きます。
3. ビルド構成を `Release` (または `Debug`) / `x64` に設定します。
4. `Ctrl + Shift + B`（または [ビルド] ➔ [ソリューションのビルド]）を押してビルドを実行します。

## 🎮 使い方（Usage）

### 1. アプリの起動
* `Programming_Quiz_App` フォルダ内の **`QuizApp.exe`** をダブルクリックして起動します。

### 2. クイズの進行
1. 画面に問題文と4つの選択肢（A, B, C, D）が表示されます。
2. 回答として `A`, `B`, `C`, `D` のいずれかのキーを入力し、`Enter` を押します。（※小文字の `a`, `b`, `c`, `d` でも可）
3. 正解・不正解と解説が表示されたら、`Enter` キーを押して次の問題に進みます。
4. 途中終了したい場合は `Q` キーを入力して `Enter` を押します。

### 3. 問題の追加・編集方法
`data/quiz_list.csv` をメモ帳や Excel 等で編集することで、クイズ問題を自由に追加・変更できます。

**CSVのフォーマット仕様:**
```csv
ID,問題文,選択肢A,選択肢B,選択肢C,選択肢D,正答,解説
1,"C++で画面に出力する命令は？","std::cin","std::cout","std::endl","printf","B","画面出力には std::cout を使用します。"
```
